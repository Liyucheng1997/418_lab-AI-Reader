# AI Reader

参照 Neat Reader 做的桌面电子书阅读器，界面使用 apple-minimal 设计语言，并新增两项功能：

- **多级文件夹分类（类似 Zotero）**：文件夹可以无限嵌套；一本书可以同时放在多个文件夹里；拖拽图书到文件夹即可归类，拖拽文件夹可以排序或嵌套；可选“在文件夹中显示子文件夹的书”。导入整个文件夹时会按原目录结构自动建好文件夹。
- **AI 辅助阅读**：填入自己的 API Key 后，选中文字即可“AI 解释 / 翻译”，也可以一键总结本章、讲解本页、列关键概念、出思考题，或自由提问。AI 会自动附带当前章节或当前页的原文作为上下文。回答可以保存到笔记。

## 功能一览

| 模块 | 功能 |
| --- | --- |
| 格式 | EPUB、PDF、TXT（自动识别 UTF-8 / GBK，自动分章）、MOBI、AZW3、FB2、CBZ |
| 书库 | 封面 / 列表视图，按最近阅读、添加时间、书名、作者、进度排序，搜索，收藏，阅读状态，格式分类，多选批量操作，拖入文件导入，自动解析书名、作者、封面；关联 OneDrive 等文件夹（不复制，按原分类建索引，标注本地 / 云端） |
| 阅读 | 分页 / 滚动、单栏 / 双栏，字体、字号、行距、段距、边距、版心宽度，五种背景（白、米黄、护眼、浅灰、夜间，PDF 页面也会染成所选纸色），PDF 适应页面 / 宽度；扫描版 PDF 自动 OCR，可直接选中、复制、做笔记 |
| 标注 | 五色高亮、下划线、笔记、书签，笔记面板按颜色筛选，导出 Markdown |
| 朗读 | F5-TTS 本地语音大模型（与“静听”听书软件同一模型），语气自然，可用静听里的音色或克隆任意人声；高亮正在读的句子，朗读中双击任意一句即从那里读起；按章连续朗读、页面跟着翻，翻页和换章都不停顿；变速不变调；也可切回系统语音 |
| 其他 | 目录、全文搜索、进度条跳转、全屏、深色模式、老板键（默认 Alt+Q）、双击文件用本程序打开 |

## 关联文件夹（OneDrive）

导入 → “关联文件夹（OneDrive 等，不复制）…”，或在“设置 → 通用 → 关联文件夹”里添加。

- 书不复制，直接读原文件；原来的文件夹结构照搬成书库文件夹（如 我的电子书仓库 → 01_哲学政治 → 01_中国哲学）。
- 每本书标注“本地”或“云端”（按 OneDrive 的文件属性判断，扫描时不会触发下载）；左侧“位置”里可以只看本地或只看云端的书。打开云端的书时 Windows 会自动把这一本下载下来。
- 书名、作者、封面只从本地的书里读取，不会因为建索引把整个 OneDrive 下载下来；没有封面的书（包括只在云端的）按书名去 Google Books / Open Library 查找（设置里可关闭；填自己的 Google Books API Key 查中文书更稳定）。
- 启动时自动重新扫描；重新扫描后阅读进度和笔记不变，在 OneDrive 里直接移动过的书（同名同大小）也会保留。
- 当作仓库管理工具用，书库里的操作会同步改动 OneDrive：
  - 删除关联的书 = 删除本地副本、只留在云端（OneDrive 的“释放空间”）；也可以“下载到本地”，或对整个文件夹“全部下载 / 释放本地空间”。
  - 把书拖到（或“添加 / 移动到”）关联文件夹 = 在 OneDrive 里移动文件；导入的书拖进去会放进 OneDrive 目录。
  - 在关联文件夹里新建、改名、拖动文件夹 = 在 OneDrive 里建目录、改名、移动目录；删除目录请在 OneDrive 里做。
- 索引大小：约 0.6 KB / 本（3000 多本约 2 MB），封面缩略图约 25 KB / 张。

## 数据位置

书库索引、封面、笔记、导入的书和语音缓存默认在 `%APPDATA%/AI Reader`（C 盘）。“设置 → 通用 → 数据位置 → 更改…”选一个 C 盘以外的文件夹，会把这些一起搬过去并自动重启，旧位置只留一个记录新位置的 `location.json`。

## AI 服务

在“设置 → AI 助手”中选择服务商并填入 API Key：

- **Anthropic Claude**（默认模型 `claude-opus-5-5`），通过官方 SDK 调用；
- **OpenAI 兼容接口**：OpenAI、DeepSeek、通义千问、Kimi、智谱、硅基流动、OpenRouter 或自定义地址。

Key 只保存在本机的应用数据目录中。

## 扫描版 PDF 自动识别文字（OCR）

打开扫描版或复制出来是乱码的 PDF 时，后台自动识别文字，不用任何操作：先识别正在看的页，再从这里往后，最后整本书。识别好的页铺一层透明文字，和普通 PDF 一样可以选中、复制、高亮、做笔记、朗读（逐句高亮）、搜索，也能交给 AI 助手。

- 模型：PaddleOCR 的 PP-OCRv4（中英文），用 onnxruntime-web 在一个隐藏窗口里多线程运行，不卡阅读界面，不需要联网或 Python。
- 速度：首页打开后约 5 秒可选中，之后每页约 2–4 秒；识别结果按书存在数据目录的 `library/ocr/` 里，下次打开直接用。
- 进度只在底栏显示一行“识别文字 · 还剩 N 页”。

## 朗读（F5-TTS）

点阅读页右上角的喇叭开始朗读，正在读的句子会以浅蓝色高亮。朗读中双击页面上任意一句，就从那一句接着读；没在朗读时，选中文字后在浮动工具条里点“朗读”也能从那里开始。右键喇叭进入“设置 → 朗读”选择音色和语速。

- 默认使用“静听”听书软件（`114_听书软件`）现成的 Python 环境 `.venv`（已装好 GPU 版 PyTorch 和 F5-TTS），静听里添加的音色会自动出现在音色列表；也可以在设置里手动指定装有 `f5-tts` 的 `python.exe`。
- 第一次朗读时会在后台启动 `electron/f5_server.py`（只监听 127.0.0.1）并把模型加载到显卡，约 20 秒；之后每段 1–2 秒合成，并提前合成后两段；快读完一章时先把下一章开头合成好。合成结果缓存在 `%APPDATA%/AI Reader/tts-cache/`。
- 找不到 F5-TTS 环境或合成失败时，自动改用系统语音并提示。

## 运行

```bash
npm install
npm run dev      # 开发模式（Vite 热更新 + Electron）
npm start        # 构建后运行
npm run dist     # 打包 Windows 安装程序 → release/AI-Reader-Setup-<版本>.exe
```

## 发布与自动更新

已安装的程序启动 5 秒后会检查 GitHub Releases，发现新版本就在后台下载，下载完成后右下角提示“重启更新”；不点的话，下次退出时也会自动安装。“设置 → 关于”里可以手动检查更新或关闭自动检查。

改完代码、提交后，一条命令发布新版本：

```bash
npm run release -- patch   # 1.1.0 → 1.1.1，自动提交、打 tag、推送、打包并上传到 GitHub Releases
```

也可以用 `minor`、`major` 或具体版本号（如 `1.2.0`）。发布需要先用 `gh auth login` 登录 GitHub，发布说明取自上个版本以来的提交标题。仓库需保持公开，客户端才能匿名读取 Releases。上传内容包括安装包、`.blockmap`（增量下载用）和 `latest.yml`（客户端靠它判断最新版本），缺了 `latest.yml` 客户端就检测不到更新。

应用图标由 `scripts/make-icon.ps1` 生成到 `build/icon.png`。

数据默认保存在 `%APPDATA%/AI Reader/library/`（图书副本、封面、笔记、AI 对话），可以在设置里换位置；卸载程序不会删除这些数据。

## 结构

```
electron/      主进程：书库存储、导入、自定义协议、AI 调用、自动更新、F5-TTS 朗读服务
src/library/   书库界面：侧栏文件夹树、网格 / 列表、右键菜单、拖拽
src/reader/    阅读器：翻页、标注、目录、搜索、排版、朗读、AI 面板
src/lib/       foliate-js 加载、TXT 分章、弹层组件
public/foliate-js/  渲染引擎 foliate-js（MIT），含少量兼容性修改（标注 “AI Reader”）
```
